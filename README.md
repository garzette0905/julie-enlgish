# 쥴리 잉글리쉬 홈페이지

동백 Julie's English Academy(쥴리 잉글리쉬 영어교습소) 홈페이지입니다.
Cloudflare Workers 위에서 돌아가고, 데이터는 D1(SQLite), 사진·동영상은 R2에 넣습니다.

주소: <https://www.julieenglish.co.kr>
(www 없이 <https://julieenglish.co.kr> 로도 열리고, 예전 주소 <https://julie-enlgish.wepiclab.workers.dev> 도 그대로 동작합니다)

앞으로 개발할 내용은 [ROADMAP.md](ROADMAP.md) 에 정리해 두었습니다.

## 화면

| 메뉴 | 주소 | 설명 |
| --- | --- | --- |
| 학원소개 | `#/` | 홈. 소개·수업·과정·합격 실적·연락처 |
| 상담신청 · 문의 | `#/contact` | 방문자가 상담신청/문의를 남기는 곳. 접수되면 원장님에게 즉시 알림 |
| 나의 수업 | `#/my` | 로그인한 학원생의 클래스와 일정 (로그인 전이면 로그인 화면) |
| 로그인 | `#/login` | 로그인 · 회원가입 (아이디 중복확인 포함) |
| 재원생 · 졸업생 · 학부모 후기 | `#/reviews` | 사진과 함께 후기를 남기는 곳. 익명도 쓸 수 있고, 본인 비밀번호로 수정·삭제 |
| 학원 소식 | `#/about` | 사진·동영상 갤러리, 찾아오시는 길 |

관리자 화면은 여섯 갈래입니다.

- **상담 요청** — 홈페이지로 들어온 상담신청/문의 확인, 신규/연락중/완료 관리, 처리 메모
- **학부모 알림** — 클래스별 원생 명단에서 대상을 골라 그 학부모에게 보낼 알림 내용 작성, 학부모 번호 확인 (발송은 준비 중)
- **원비관리** — 월별 원비 금액·납부 여부·특기사항, 미납 알림 대상 선택 (발송은 준비 중)
- **학원생 관리** — 등록/수정/삭제, 가입 승인, 클래스 연결, 학교·학년·반·특기사항, 상담일지
- **클래스 관리** — 클래스 생성(요일·시작시간·수업길이 지정), 수강생 확인
- **학원 소식** — 사진·동영상 파일 업로드(R2), 유튜브 링크 등록
- **졸업생 관리** — 졸업생 명단 등록/수정
- **방문 통계** — 누가 얼마나 들어왔는지, 어느 메뉴를 주로 보는지 (아래 메모 참고)
- **사이트 설정** — 홈 상단 모집 배너, 전화·이메일·주소 등

  styles.css       디자인 토큰과 모든 화면 스타일
  app.js           라우터 (#/ 해시 기반)
  js/core.js       공통 도구 — DOM, API 호출, 세션, 모달, 토스트
  js/public-pages.js  학원소개 · 시간표 · 졸업생 · 학원안내
  js/account.js    로그인 · 회원가입 · 나의 수업 · 내 정보

  assets/          로고 (원본 .ai 에서 뽑은 투명 PNG)

migrations/        D1 스키마
scripts/           비밀번호 해시 생성기

## 개발

```bash
npm install
npm run db:local     # 로컬 D1 에 스키마 넣기 (처음 한 번)
npm run dev          # http://localhost:8787
```

## 배포

`main` 브랜치에 push 하면 Cloudflare Workers Builds 가 자동으로 빌드·배포합니다.

스키마를 바꿨을 때만 마이그레이션을 따로 적용합니다.

```bash
npm run db:remote
```

## 메모

- 비밀번호는 PBKDF2-SHA256(10만 회)으로 해시해서 저장합니다. 평문은 어디에도 남지 않습니다.
- 로그인 세션은 HttpOnly·Secure 쿠키 30일이고, 관리자가 비밀번호를 재설정하면 그 회원의 세션은 모두 끊깁니다.
- 회원가입은 `승인대기` 상태로 들어옵니다. 관리자가 승인해야 로그인됩니다.
- 시각은 DB에 **UTC로 저장**합니다(D1의 `datetime('now')`). 세션 만료·중복 접수 검사처럼
  DB 안에서 시각끼리 비교하는 곳이 있어 기준을 하나로 두는 편이 안전합니다.
  화면에 낼 때는 `core.js` 의 `kstDate()` / `kstDateTime()` 을 거쳐 한국시간으로 바꿉니다.
  타임스탬프를 새로 화면에 뿌릴 때는 반드시 이 함수를 쓰세요.
- 회원은 학부모 연락처(`parent_phone`, 필수)와 학생 연락처(`phone`, 선택)를 따로 받습니다.
  학부모 알림·상담 연락은 모두 `parent_phone` 으로 갑니다.
- 업로드는 한 파일당 95MB까지입니다. 그보다 긴 영상은 유튜브 링크로 등록하세요.
- 후기가 작성·수정·삭제되면 원장님에게 알림이 갑니다.
- 후기는 익명으로도 쓸 수 있습니다. 익명 글은 글쓴이가 정한 비밀번호(PBKDF2 해시)로만
  수정·삭제되고, 원장님은 비밀번호 없이 모든 글을 지울 수 있습니다.
- 상담신청·문의는 먼저 DB(`inquiries`)에 저장한 뒤 알림을 보냅니다. 알림이 실패해도
  접수 내용은 남고, 관리자 화면에 "알림 전송 실패" 표시가 붙습니다.
- 방문 통계(`visits` 테이블)는 **동의를 받아야 하는 정보를 모으지 않습니다.** 추적 쿠키를
  심지 않고, IP 원본도 저장하지 않습니다. 사람 구분은 `그날치 무작위 소금 + IP + 브라우저 정보`
  를 SHA-256 으로 해시한 값 하나뿐이고, 그 소금(`visit_salts`)은 사흘 뒤에 지웁니다.
  날이 바뀌면 값이 통째로 달라져서 어제 온 사람과 오늘 온 사람을 이어 붙일 수 없습니다
  (그래서 화면의 "방문자 수"는 하루 기준입니다). 원장님 본인 접속(`is_admin`)과 검색로봇은
  세지 않고, 브라우저가 `DNT` · `Sec-GPC` 를 보내면 아예 기록하지 않으며, 기록은 2년치만
  남기고 자동으로 지웁니다. 화면을 하나 열 때마다 `public/js/core.js` 의 `trackVisit()` 이
  `POST /api/track` 을 부르고, 관리자 화면은 `GET /api/admin/stats?days=…` 로 집계만 읽습니다.
- 알림 수신 설정은 워커 시크릿으로만 넣습니다(레포에 올리지 않습니다).
  로컬 개발은 `.dev.vars` 에 같은 두 값을 두면 됩니다.

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN --name julie-enlgish
```
